# https://munich-nlp.github.io

## Local Development

In `config.toml` set `production = true` to `production = false`. Reset this parameter before commit!

Run hugo server with
```bash
hugo -F server
```

## Downsize Images

Photos in the page templates and Markdown content are resized and converted to responsive WebP images during the Hugo Extended build. Keep originals in `static/images/`; the `images/optimized.html` partial handles delivery sizes and lazy loading. Its `widths` and `sizes` parameters can be adjusted for each layout.

The hero uses a cropped source in `assets/images/munich-hero.webp`, with a separate mobile crop generated by Hugo. The original photo remains in `static/images/munich-hero.jpg`.

For manual downsizing:

1. Install PIL.
2. Run `python downsize.py [args]` (`--help` for more information)
